# Security policy

## Supported versions

Security fixes go into the latest release. Please update to the newest version before reporting.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/thabetrighi/nashir/security/advisories/new)
with:

- the Nashir version and Windows version;
- a minimal document (or steps) that reproduces the issue;
- the impact you observed.

We aim to acknowledge reports within 3 working days and to ship a fix or mitigation within 30 days, crediting you in the release notes unless you prefer otherwise.

The threat model and mitigations are described in [docs/security-and-privacy.md](docs/security-and-privacy.md).
