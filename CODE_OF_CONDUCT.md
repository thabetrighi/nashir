# Code of Conduct · مدونة السلوك

Nashir welcomes everyone who wants to make reading better — in any language, at any experience level.

## Our standards

- Be kind and patient; assume good intent. Many contributors write in their second or third language.
- Welcome questions, including beginner ones, in Arabic, English or French.
- Critique ideas and code, never people.
- No harassment, insults, discrimination, sexualized language or imagery, or publishing others' private information.

## Scope and enforcement

This applies in issues, pull requests, discussions and any space representing the project. Report problems privately to the maintainer through GitHub (profile contact or a private security advisory for sensitive cases). Maintainers may edit or remove contributions and temporarily or permanently ban participants who break these standards.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
